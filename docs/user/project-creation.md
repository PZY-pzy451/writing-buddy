# Create a project

You can create a project even when no project is open:

1. Select **New** in the top bar or **New project** on the welcome page.
2. Enter a project name and choose the parent folder where it will be stored.
3. Pick one of the six templates and adjust the initial resources.
4. Choose the project theme, accent, and the page to open after creation.
5. Review the final path and select **Create project**.

Writing Buddy first builds the project in a temporary sibling directory,
reopens it for verification, and only then saves it to the final path. An
existing folder is never overwritten.

The theme and accent belong to the project and are restored the next time it
is opened. Templates do not generate novel prose and do not call an AI
provider automatically.
