# 2026-08-01

## Phase 1.2G chapter completion and export trust

- Audited the remaining market-journey gap after Phase 1.2F. `整理本章`
  already reached the chapter-scoped extraction and reconciliation center, but
  chapter export was only available as a save-recovery fallback and History had
  no export receipt.
- Added safe Markdown and plain-text chapter export. Dirty manuscripts save
  first; cancellation, failed saves and failed copies create no receipt.
- Added durable, project-scoped export receipts with guarded parsing and a
  maximum history size. Receipts include destination, format, chapter, words
  and time only after the copy succeeds.
- Reworked History into `历史与导出` with one primary export task, recent
  receipts and the existing snapshot/restore safety workflow.
- Real browser acceptance found that the longer chapter menu clipped its final
  density option at 1440×900. Added viewport-bounded scrolling and passed
  1440×900, 1280×800, 1024×720 and 820×720 with no overflow, clipped controls
  or runtime errors.
- The optional UI/UX design-system search helper was absent, so its documented
  accessibility and interaction rules were applied directly: one primary
  action, standard icon tiers, 44 px actions, visible focus and responsive
  stacking.
- Full self-test passed: 161 Vitest files / 639 tests, production build, Rust
  format and 68 Rust tests / 2 ignored external gates.
- Tauri Release and NSIS built successfully. Portable PID 37408 reached input
  idle, was responsive with title `Writing Buddy`, had one direct WebView2
  child, no 9223/9751 listeners, accepted normal close and exited with code 0.
- Delivery: `artifacts/release/phase-1.2g-chapter-export-trust-2026-08-01/`;

## Phase 1.2H whole-work export and backup trust center

- Audited the post-Phase-1.2G market gap and chose whole-work completion over
  file import because project-order chapter reads and native text saving were
  already available, while `导出作品` remained the explicit History task in the
  market brief.
- Added deterministic whole-work Markdown/plain-text assembly across every
  volume and chapter. Source files are unchanged; scene anchors are removed,
  matching duplicate chapter headings are avoided and prose words are counted
  separately from generated structure headings.
- Extended durable export receipts with work/chapter scope and chapter count.
  Legacy Phase 1.2G receipts migrate as chapter receipts through guarded parsing.
- Moved the existing `.wbbackup` workflow into a reusable component shared by
  History and the task dock. Restore stays unavailable until native inspection
  succeeds and retains explicit confirmation plus pre-restore snapshot safety.
- Real browser acceptance found the new History grid compressing the backup
  card to 2 px. Content-sized implicit rows fixed it; the runner now asserts the
  panel is at least 120 px high. Four viewports pass with zero overflow, clipped
  controls, sub-44 px History controls or runtime errors.
- The first full self-test rejected three 17 px icons under the visual contract.
  Standardizing them at 18 px made the focused and complete reruns pass.
- Final gates: 161 Vitest files / 643 tests, production Vite build, Cargo format,
  68 Rust tests / 2 ignored, Tauri Release/NSIS and isolated portable PID 41308
  responsive/title/WebView/no-debug-port/normal-close smoke.
