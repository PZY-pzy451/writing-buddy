## Phase 1.2J Word interoperability

- Ranked the next market gap with RICE. Word import plus whole-work Word
  delivery scored 51 and was selected ahead of daily goals, one-click
  consistency checking and a scene plot grid.
- Extended the native import picker to `.docx`, `.md`, `.markdown` and `.txt`.
  Word files are parsed as untrusted ZIP/XML with explicit limits for archive
  size, entry count, main-document size and extracted text. Encrypted,
  malformed, empty, oversized or missing-main-document packages fail before a
  project is created.
- Kept Word import deterministic and honest: visible body paragraphs, tabs and
  line breaks are extracted; images, comments, footnotes, tracked revisions and
  exact layout are not claimed. Manuscripts enter the first chapter without AI
  rewriting, while explicit outline headings reuse the existing analyzer and
  atomic staging/reopen/rename transaction.
- Added structured native `.docx` export with Title, Heading 1, Heading 2 and
  Normal styles. Export preserves work/volume/chapter order, strips internal
  scene anchors and duplicate chapter headings, escapes author text and writes
  atomically. History now has exactly one primary delivery action: `导出 Word 文档`.
- Reused durable export receipts for Word. Cancellation, failed dirty saves and
  failed writes remain fail-before-receipt.
- Added focused TypeScript and Rust regressions plus a four-viewport browser
  acceptance journey. The bundled in-app browser bootstrap failed twice with a
  runtime initialization conflict, so the repository's isolated Edge/CDP
  driver exercised the same browser bridge instead. All views reported zero
  horizontal overflow, clipped controls, short History controls and runtime
  errors.
- A literal hostile DTD/entity fixture embedded in the Rust test binary caused
  multiple Windows antivirus products to quarantine the executable. Removing
  the signature-like payload resolved the false positive without weakening the
  production parser's `DocType` rejection. The durable testing lesson is in
  `docs/postmortem/007-security-fixture-antivirus-false-positive.md`.
- Final verification passed: 4 focused files / 35 tests, ESLint, TypeScript,
