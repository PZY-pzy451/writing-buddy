# 2026-07-27

## Decisions

- Keep the Phase 1.0A provider surface deliberately narrow: one DeepSeek BYOK
  provider and one isolated StoryForge test flow.
- Keep provider HTTP, credential reads, streaming, retries, timeouts, and
  cancellation in Rust. React receives only scoped commands and public events.
- Accept only current runtime model identifiers returned by `/models`;
  `deepseek-v4-flash` and `deepseek-v4-pro` are the local preferences, while
  retired `deepseek-chat` and `deepseek-reasoner` identifiers are rejected.
- Persist only non-sensitive preferences, a short-lived model cache, and
  anonymous token usage. Never persist prompts, outputs, private reasoning, or
  key material.
- Hide the task dock and assistant column on system pages so AI Settings and AI
  Test keep a usable desktop canvas.
- Keep real-key validation and M9 human cutover as explicit manual gates.
