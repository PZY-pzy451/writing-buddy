# Work log — 2026-07-29

## VS Code-style workspace resizing start

- The user supplied a P1 screenshot marking the project-sidebar boundary,
  assistant boundary, and task-dock boundary as not behaving like VS Code.
- Audit confirmed that the shared `ResizeHandle` updates state, but
  `workspace.css` ignores sidebar/assistant user values below 1600px and hides
  all handles below 1280px.
- Side-panel overflow also reduces the effective pointer acquisition area.
- The repair will keep one accessible shared separator, use explicit bounds,
  preserve persisted sizes, support pointer and keyboard resizing, and keep
  responsive overlay panes resizable without introducing page overflow.
- `ui-ux-pro-max` was read completely. Its required `scripts/search.py` is
  missing, so its focus, interaction target, responsive, contrast, and
  reduced-motion rules are applied directly.
- Contract: `docs/plans/022-vscode-style-workspace-resizing.md`.

## VS Code-style workspace resizing completion

- A second root cause appeared in browser geometry: effective CSS variables
  were declared on `:root`, but React supplied user variables on `.app-shell`.
  Moving effective values to the shell made actual grid dimensions match
  Zustand and separator ARIA values.
- Shared pane bounds are sidebar 220/320/440, assistant 280/360/480, and dock
  144/240/420.
- Pointer drag, keyboard resize/reset, responsive visibility, persistence,
  Paper/Midnight rendering, and zero horizontal overflow were verified at
  1536, 1280, and 1024 widths.
- Final gates: 99 frontend files / 344 tests, 51 Rust tests, fresh Tauri EXE
  and NSIS package, and isolated native exit code 0.
- Evidence:
  `docs/acceptance/030-vscode-style-workspace-resizing-2026-07-29.md`.

## Workspace layout shortcuts start

- Follow-up feedback identified that resize separators had focused keyboard
  controls but the workspace still lacked global pane shortcuts.
- Chosen mappings: Ctrl/Cmd+B for the project sidebar, Ctrl/Cmd+Alt/Option+B
  for the writing assistant, and Ctrl/Cmd+J for the task dock.
- Shortcuts will be discoverable from button titles, ARIA key metadata, and
  Settings > Appearance.
- Contract: `docs/plans/023-workspace-layout-shortcuts.md`.
