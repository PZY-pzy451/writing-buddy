# 127 写作辅助控件与导航追踪收敛 QA

## 目标

- 清零 `StoryReferenceSidebar`、`InlineDraftCard` 与 `UndoToast` 的 3 个稳定选择器缺口。
- 让故事库导航的两个既有未映射用例获得真实控件/状态映射。
- 复用既有临时草稿和撤销提示测试，覆盖作者写入、阻断、丢弃和撤销操作。
- 不增加测试总数，保留现有用户路径并补充精确控件断言。

## 基线

- 基线提交：`b3aa9a4`
- 严格追踪缺口：8,623
- 缺少稳定选择器：22
- 未映射测试：800
- 稳定选择器覆盖：500 / 522（95.79%）
- 测试映射覆盖：258 / 1,058（24.39%）
- 严格覆盖：4,694 / 13,317（35.25%）

## 失败优先契约

1. 每个故事库/规划导航项必须保留稳定选择器和精确 `StoryViewId`。
2. 导航测试必须真实覆盖指针选择、Arrow/Home/End 键盘移动和焦点落点。
3. AI 临时草稿写入按钮必须有独立稳定选择器，并保持陈旧或空内容阻断。
4. 撤销提示的主撤销动作必须有独立稳定选择器，并与关闭动作区分。
5. inventory 必须证明三个目标源文件不再含匿名控件。
6. 不允许仅靠 QA 元测试制造映射；产品测试必须引用精确选择器并观察用户可见或可持久化结果。
