## 失败优先契约

1. 每个动态控件必须提供稳定类型选择器和精确业务 ID。
2. 项目菜单项必须区分新建项目与打开项目。
3. 备份操作必须区分创建、选择与恢复，且恢复仍受完整性检查保护。
4. 作者导航结果必须保留结果 ID 与结果类型，预览不能改变当前章节。
5. 写作工具项必须保留工具 ID，重复点击只能确定性切换当前面板。
6. AI 创建的物品必须可通过稳定物品 ID 重新选择。
7. inventory 必须证明五个目标源文件不再含匿名控件。
