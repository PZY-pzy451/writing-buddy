# 129 动态导航与恢复操作追踪收敛 QA

## 目标

- 清零项目菜单项、便携备份操作、物品列表项、作者导航结果和写作工具栏项的 5 个稳定选择器缺口。
- 将作者导航与便携备份的既有未映射用户路径迁移到权威测试源。
- 强化项目菜单与写作工具栏既有用例，并用写作页测试补足工具栏权威映射。
- 保持运行时测试总数不增长，并通过重复点击验证动态控件不会漂移或重复执行。

## 基线

- 基线提交：`80dc4d9`
- 严格追踪缺口：8,558
- 缺少稳定选择器：15
- 未映射测试：796
- 稳定选择器覆盖：507 / 522（97.13%）
- 测试映射覆盖：262 / 1,058（24.76%）
- 严格覆盖：4,759 / 13,317（35.74%）

## 失败优先契约

1. 每个动态控件必须提供稳定类型选择器和精确业务 ID。
2. 项目菜单项必须区分新建项目与打开项目。
3. 备份操作必须区分创建、选择与恢复，且恢复仍受完整性检查保护。
4. 作者导航结果必须保留结果 ID 与结果类型，预览不能改变当前章节。
5. 写作工具项必须保留工具 ID，重复点击只能确定性切换当前面板。
6. AI 创建的物品必须可通过稳定物品 ID 重新选择。
7. inventory 必须证明五个目标源文件不再含匿名控件。
