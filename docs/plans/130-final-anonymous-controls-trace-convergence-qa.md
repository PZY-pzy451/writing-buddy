## 失败优先契约

1. 每个集合型控件必须同时提供稳定类型选择器和精确资源、项目、问题或字段 ID。
2. 最近项目、资源标签、伏笔和反向链接必须可按业务 ID 定位，不能依赖显示顺序或文案。
3. 场景规划生成必须保持单飞；候选字段必须保留字段 ID，应用动作必须有独立身份。
4. 任务区问题行必须保留问题 ID，发布检查跳转必须能定位同一问题。
5. 资料编辑器的单行与多行字段必须共享稳定类型选择器，同时保留字段 ID。
6. inventory 必须证明 8 个目标源文件不再含匿名控件，且全局选择器缺口为 0。
