## 目标

- 修复 Plot Board 与 Plot AI Panel 的全部稳定选择器缺口。
- 复用既有页面测试验证剧情线选择、生命周期草稿、AI 打开入口、隐私开关、

## 失败优先契约

1. 剧情线主卡必须暴露稳定选择器与精确剧情线 ID。
2. 生命周期选择框必须暴露稳定选择器与精确剧情线 ID。
3. 两个 AI 打开入口共享稳定选择器，并以入口上下文区分。
4. AI 动作、生成、开关、作者指令与候选选择必须可稳定定位。
5. 页面测试必须真实操作上述控件，并保留 100 次生成防重断言。
6. inventory 必须证明 Plot Board 与 Plot AI Panel 不再含匿名控件。
