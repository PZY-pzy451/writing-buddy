# QA documentation

- [Current defect convergence](./001-defect-convergence-2026-08-03.md) records the repaired test-discovery and Windows runner defects, user-centered stress results, exact source commit, and remaining release gates.
- [Full regression scope](./full-regression-scope.md) defines the Gates A-E boundary, source map, status vocabulary, commands, and first-baseline policy.
- [First Gates A-E baseline](./first-baseline.md) records actual execution, inventory/traceability counts, cache state, warnings and the stop line.
- Machine-readable inventories, traceability, dependency maps, ledgers, and reports are tracked under `artifacts/qa/`.
- Historical acceptance evidence remains useful context but is never treated as current after a source, schema, fixture, mock, environment, build-configuration, or test-implementation fingerprint changes.
