# Phase 1.2B Gate D — 局部生成与作者控制

日期：2026-07-30

## 目标

在既有结构化大纲工作区内完成作者可控的局部 AI 修订闭环：

1. 只针对作者选中的未锁定故事节点生成候选。
2. 每次严格返回三个实质不同的候选。
3. 显示当前值与候选之间的字段级 Diff。
4. 允许作者逐字段选择并部分采用。
5. 采用前检查节点版本与锁，创建标准安全快照，再进行一次原子项目写入。
6. 采用后展示精确影响报告，并提供带版本保护的撤销。
7. 不创建卷、章节、场景或 Story Kernel 资源。

## 复用边界

- 继续使用 `.writing-buddy/creation/journey.json` 与 `CreationJourneyStore`。
- 继续使用 `StoryOutline` / `StoryOutlineNode`，不创建第二套大纲模型。
- 继续使用 `locks.outlineNodeIds` 作为唯一节点锁来源。
- 继续使用 `desktopBridge.createSnapshot(..., 'beforeDestructiveOperation', ...)`。
- 继续使用 Tauri 的 `write_creation_journey_state` 期望哈希原子写入。
- 继续使用 `creation-journey` AI job、统一 AI 设置、取消与进度通道。
- 候选是临时审核数据，不写入项目；只有作者确认的字段才进入项目状态。

## 严格契约

新增 `generate-outline-alternatives` 请求：

- 输入只包含目标节点、相邻节点、故事总纲的有限字段、作者选择的策略、
  已确认约束和锁定决定。
- 禁止项目 ID、根路径、密钥、账户、隐藏历史和正文。
- 若目标本身已锁定，TypeScript 与 Rust 均在请求前拒绝。
- 相同请求只允许一个在途任务；结构异常只进行一次有界修复。

输出：

- `targetId` 必须与请求完全一致。
- `alternatives` 必须恰好为三个。
- 每项包含简短标签、依据和完整可比较节点字段。
- 三项 replacement 必须实质不同。
- Markdown、额外字段、错误 target、路径文本与无效长度全部拒绝。

## 作者控制事务

采用顺序固定为：

`Preview → Validate revision → Check locked → Create snapshot → Atomic save → Show impact → Offer undo`

- `baseJourneyRevision` 与 `baseNodeRevision` 任一变化都把候选标记为过期。
- 只能选择实际发生变化的字段，至少选择一个字段。
- 未选字段保持当前作者内容不变。
- 快照失败时不修改内存或项目文件。
- 原子写入失败时不修改可见状态。
- 撤销仅在采用后的项目/节点版本仍匹配时可用，避免覆盖后续作者编辑。

## 影响报告

报告是分析，不是自动传播：

- 列出本次实际采用的字段。
- 列出目标节点与它之后的现有故事节点。
- 标记下游锁定节点，明确它们未被修改。
- 明确当前阶段尚未物化卷、章节、场景或正文，因此没有隐式重写。

## UI

- 节点详情提供“生成 3 个局部候选”及策略选择。
- 候选审核区显示 Current / A / B / C，可键盘切换。
- 每个变更字段均有独立复选框与“当前 / 候选”内容。
- 主按钮文案明确显示将采用的字段数量。
- 生成和应用期间禁用重复操作。
- 锁定、过期、快照失败与空选择均显示就地可理解错误。
- 交互目标不小于 44px；焦点可见；1024px 与窄屏不横向溢出。

## TDD 与验收

1. AI 合同：三候选、目标匹配、锁、隐私、一次修复、重复请求合并。
2. 模型：字段 Diff、部分采用、版本保护、锁保护、影响报告、撤销保护。
3. 组件：生成入口、候选切换、字段选择、部分采用、锁定禁用、Undo。
4. 页面/存储：快照先于写入，失败零写入，采用和撤销均原子持久化。
5. Rust：接受安全的局部候选请求，拒绝锁定目标、未知字段、路径和越界值。
6. 原生 Tauri：真实点击生成 fixture、选择部分字段、快照、保存、重开、撤销；
   检查 1536×992、1280×800、1024×720。
7. 全量 TypeScript、ESLint、Vitest、生产构建、Cargo fmt/test、Release/NSIS。

## 停止条件

Gate D 验收、报告和提交完成后停止。不得进入 Gate E 的卷、章节、场景物化。
